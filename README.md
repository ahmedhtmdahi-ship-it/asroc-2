# نظام إدارة الخدمات الطبية

نظام شامل لإدارة الخدمات الطبية في المؤسسات والشركات، يدعم أدوار متعددة للمستخدمين مع واجهة عربية كاملة.

> ملاحظة: هذا الريدمي مكتوب ليكون جاهز للمراجعة داخل GitHub ويحتوي على خطوات تشغيل سريعة ووصف واضح للوظائف.

## المميزات الرئيسية


### 📋 إدارة طلبات الكشف الطبي
- طلبات كشف عادي (3 كشوف شهرياً للموظف)
- طلبات كشف طوارئ (تُعتمد تلقائياً)
- تتبع حالة الطلبات (قيد الانتظار، معتمد، مرفوض، مكتمل)

### 👔 نظام موافقات المديرين
- مراجعة طلبات الموظفين
- الموافقة أو الرفض أو التأجيل مع إمكانية إضافة ملاحظات
- عرض تفاصيل شاملة لكل طلب

### 🛡️ نظام الأمن
- تسجيل خروج الموظفين للكشف الطبي
- تسجيل العودة للمبنى
- تتبع المدة الزمنية خارج المبنى
- تنبيهات للموظفين المتأخرين عن الوقت المتوقع

### 🩺 التشخيص الطبي
- فحص المرضى وتسجيل التشخيص
- كتابة الروشتات الطبية بتفاصيل الجرعات والمدة
- إصدار تحويلات طبية خارجية
- إصدار راحات مرضية

### 💊 الصيدلية
- استقبال الروشتات من الطبيب
- صرف الأدوية مع تتبع المتوفر وغير المتوفر
- تأكيد الصرف وإغلاق الروشتة
- تنبيهات للأدوية غير المتوفرة

### 📅 العلاج الشهري
- إدارة العلاجات المزمنة للموظفين وأصحاب المعاش
- صرف العلاج الشهري في موعده
- تتبع آخر صرف والموعد القادم
- تنبيهات للعلاجات التي تحتاج مراجعة سنوية

### 🏥 الإدارة الطبية
- مراجعة حالات الطوارئ
- الموافقة على التحويلات الخارجية
- إحصائيات شاملة عن العمليات اليومية
- تقارير يومية وشهرية

### 📊 التقارير والإحصائيات
- تقارير يومية وشهرية مفصلة
- إحصائيات الأقسام المختلفة
- تحليل التشخيصات الأكثر شيوعاً
- توزيع أوقات الذروة
- تصدير التقارير بصيغة PDF و Excel

## أدوار المستخدمين

1. **موظف**: تقديم طلبات الكشف ومتابعة حالتها
2. **مدير إدارة**: الموافقة على طلبات الموظفين
3. **أمن**: تسجيل دخول وخروج الموظفين
4. **طبيب**: فحص المرضى وكتابة الروشتات
5. **صيدلية داخلية**: صرف الأدوية
6. **صيدلية خارجية**: (للتوسع المستقبلي)
7. **إدارة طبية**: مراجعة النظام والتقارير
8. **صاحب معاش**: العلاج الشهري

## التقنيات المستخدمة

- **React 18.3.1** - مكتبة بناء واجهة المستخدم
- **TypeScript** - للكتابة الآمنة
- **React Router 7** - للتنقل بين الصفحات
- **Tailwind CSS 4** - للتصميم والأنماط
- **Radix UI** - مكونات واجهة المستخدم
- **Lucide React** - الأيقونات
- **Sonner** - نظام التنبيهات
- **Vite** - أداة البناء
