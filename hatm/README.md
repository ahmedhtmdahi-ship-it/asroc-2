# حوتمة — MVP

```
شيت المهام  →  فحص الدرايف  →  قايمة المتأخرين  →  رسايل جاهزة بلينك wa.me
```

**النظام يجهّز، وإنت تبعت.** مفيش إرسال تلقائي.
وكل حالة معاها `evidence` — جملة تقدر تتأكد منها، مش تخمين.

## التشغيل من الصفر

```bash
cd hatm
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env        # عدّل القيم
python -m app.db            # ينشئ hatm.db والجداول الأربعة
```

المفروض تشوف:

```
قاعدة البيانات: /.../hatm/hatm.db
  deliverable  0 صف
  message      0 صف
  person       0 صف
  task         0 صف
```

آمن إنك تشغّله تاني — مش بيمسح حاجة. لو عايز تبدأ من أول وجديد: امسح
`hatm.db` وشغّله.

بعد ما يكمل:

```bash
# اطبع محتويات فولدر — أول حاجة تجربها بعد تسجيل الدخول
python -m app.drive https://drive.google.com/drive/folders/xxxxx

python -m app.scan          # الفحص (لسه متعملش)
uvicorn app.main:app        # الواجهة (لسه متعملش)
```

## تسجيل الدخول لجوجل

البرنامج بيشتغل **بحسابك إنت** (OAuth Desktop app)، فبيشوف بالظبط كل اللي إنت
شايفه — مشاريع إنت مديرها، ومشاريع إنت داخل عليها، وShared Drives. **مفيش
مشاركة فولدرات ولا إيميل بوت.**

```
1. console.cloud.google.com ← ادخل بحساب الشغل
2. فوق جنب اللوجو → قايمة المشاريع → New Project → سمّيه hatm → Create
3. من البحث فوق:  "Google Drive API"  → Enable
                  "Google Sheets API" → Enable
4. APIs & Services → OAuth consent screen
   → External → املا الاسم والإيميل → Save
   → Audience / Test users → Add users → حط إيميلك إنت
5. APIs & Services → Credentials
   → Create credentials → OAuth client ID
   → Application type: Desktop app → Create
   → Download JSON
6. غيّر اسمه لـ client_secret.json وحطه جوّه فولدر hatm/
```

أول مرة تشغّل حاجة بتكلم جوجل، هيفتح المتصفح لوحده. سجّل دخول، وهيطلعلك
تحذير **"Google hasn't verified this app"** — ده طبيعي، البرنامج بتاعك إنت:
اضغط **Advanced** → **Go to hatm (unsafe)** → **Continue**.

بعدها بيتعمل `token.json` ومش هيسألك تاني. عايز تسجّل بحساب تاني؟ امسحه.

**الصلاحيات:** الدرايف **قراءة بس** — البرنامج عمره ما هيلمس ملفات حد.
الشيت قراءة وكتابة، عشان الفحص يكتب عمود الحالة.

⚠️ `client_secret.json` و `token.json` **متتعملهمش commit** (في `.gitignore`).
وميتبعتوش لحد.

## الجداول الأربعة

| الجدول | بيحفظ إيه |
|---|---|
| `person` | الفريق. `drive_email` لازم يطابق اللي الدرايف بيرجّعه، و`phone` دولي بدون `+` (`201012345678`) عشان `wa.me` |
| `task` | مهمة من الشيت + حالتها + **الدليل** |
| `deliverable` | ملف اتلاقى في فولدر المهمة، زي ما الدرايف رجّعه |
| `message` | رسالة مجهّزة + لينك `wa.me`. مبتتبعتش من النظام |

### قرارات في الـ schema

- **`sqlite3` من المكتبة القياسية، بدون ORM.** أربع جداول وكاتب واحد — أي ORM
  هيبقى كود تصيانه أكتر من الـ SQL اللي بيخبّيه.
- **الوقت TEXT بصيغة ISO وبتوقيت UTC** (`2026-08-17T14:40:00Z`). SQLite مالهاش
  نوع تاريخ، والـ ISO بالطول الثابت بيترتب ويتقارن كنص صح. **UTC** لأن الدرايف
  بيرجّع `modifiedTime` بالـ UTC — لو خزّنا بتوقيت محلي هنبقى بنقارن ساعتين
  مختلفتين وإحنا بنقرر «اترفع بعد الميعاد». التحويل للقاهرة بيحصل وقت العرض بس.
- **`expected` نص فيه JSON** — `json.loads(row["expected"])` وقت القراءة
  (فيه `db.loads` و`db.dumps` جاهزين).
- **`size_bytes = NULL` معناها «الدرايف مرجّعش حجم»** (ملفات جوجل الأصلية) —
  **مش صفر**. الملف اللي اترفع فاضي فعلاً بيبقى `0`، وده `bad_file`. الفرق ده
  هو اللي بيمنع رسالة غلط لحد سلّم Google Doc.
- **`CHECK` على `kind` و`status`** — الكلمات اللي في المواصفة بالظبط. غلطة
  إملائية بتفشل فورًا بدل ما تعمل حالة محدش بيتعامل معاها.
- **`sheet_row` فريد** — الشيت واحد، فالصف بيحدّد المهمة. ده بيخلي إعادة
  الفحص تحدّث المهمة بدل ما تكرّرها. (لو بقى فيه أكتر من شيت، ده أول حاجة
  تتغير.)
- **`UNIQUE(task_id, drive_file_id)`** — نفس السبب، على مستوى الملفات.
- **`supportsAllDrives` و `includeItemsFromAllDrives` دايمًا شغالين** في كل
  استدعاء للدرايف. من غيرهم فولدر الـ Shared Drive بيرجّع **ليست فاضية من غير
  أي خطأ** — تفتكر الفولدر فاضي وهو مليان. وهُمّ مش بيضروا My Drive، فمفيش
  خانة إعدادات تغلط فيها.
- **`PRAGMA foreign_keys = ON` في كل اتصال** — SQLite بتتجاهل المفاتيح
  الأجنبية افتراضيًا، ومن غير السطر ده الـ `ON DELETE CASCADE` مش بيعمل حاجة.

## حالات المهمة

| الحالة | يعني إيه |
|---|---|
| `pending` | الميعاد لسه مجاش |
| `ok` | اترفع وسليم |
| `late` | الميعاد عدى ومفيش حاجة |
| `bad_file` | اترفع بس حجمه صفر |
| `needs_fix` | اترفع بس فيه مشكلة (اسم، عدد، بعد الميعاد) |
| `unverifiable` | مالهاش ملف — النظام مش قادر يتحقق، لازم يسأل |
