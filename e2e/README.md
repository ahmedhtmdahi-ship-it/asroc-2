# اختبارات E2E (Playwright)

حزمة اختبارات شاملة (175 اختبار في 18 ملف) تغطّي الدخول، تغيير الباسورد الإجباري،
لوحات التحكم لكل الأدوار، سير عمل الطلبات، والصلاحيات على مستوى الـ API.

## التشغيل بأمر واحد (مُوصى به)

```bash
pnpm test:e2e:clean      # أو مباشرة:  ./e2e.sh
```

السكريبت `e2e.sh` بيعمل كل حاجة لوحده:

1. يوقّف أي سيرفرات قديمة على المنفذين 4000/5173.
2. يعيد ضبط قاعدة بيانات SQLite (تطوير) ويزرعها من جديد — حالة معروفة لكل تشغيلة.
3. يقلّع الـ API (بـ `NODE_ENV=test` — الـ rate-limit بيتعطّل) والواجهة تلقائيًا.
4. يشغّل كل الحزمة.

تشغيل ملف واحد أو أكتر:

```bash
./e2e.sh e2e/01-auth.spec.ts
```

## المتطلبات المسبقة (مرة واحدة)

```bash
pnpm install                       # في الجذر
cp api/.env.example api/.env       # وحُط JWT_SECRET ≥ 16 حرف
cp .env.example .env.local         # VITE_API_URL=http://localhost:4000
```

## أوامر إضافية

| الأمر | الوظيفة |
|------|---------|
| `pnpm test:e2e:clean` | **الحزمة كاملة بحالة نظيفة** (يعيد ضبط الـ DB) — للتشغيل النهائي |
| `pnpm test:e2e`       | تشغيل سريع بيعيد استخدام السيرفرات الشغالة (من غير reset) — للتطوير |
| `pnpm test:e2e:ui`    | واجهة Playwright التفاعلية |
| `pnpm test:e2e:headed`| تشغيل بمتصفح ظاهر |

بعد أي تشغيل، تقرير HTML بيتولّد في `playwright-report/` (افتحه بـ `npx playwright show-report`).
