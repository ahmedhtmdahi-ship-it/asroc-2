# ASORC Medical Services Management System
## Source Code Map

---

# Project Purpose

ASORC Medical Services Management System

Internal healthcare workflow management platform.

Built using:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Radix UI
- ShadCN UI

Current version represents Frontend Prototype.

# Pages Overview

## LoginPage

User Authentication

Responsibilities:

- Login
- User validation
- Redirect to Dashboard

Future APIs:

POST /api/auth/login

---

## DashboardPage

System overview.

Responsibilities:

- KPIs
- Active Requests
- Pending Approvals
- Emergency Cases
- Navigation

Future APIs:

GET /api/reports/dashboard

---

## EmployeeRequestsPage

Employee Medical Requests.

Responsibilities:

- Create Request
- View Requests
- Request Status
- Monthly Limits

Future APIs:

GET /api/medical-requests/my

POST /api/medical-requests

---

## RequestDetailsPage

Single Request Lifecycle.

Responsibilities:

- Timeline
- Approvals
- Security
- Diagnosis
- Prescription
- Audit

Future APIs:

GET /api/medical-requests/:id

---

## ManagerApprovalsPage

Manager Approval Workflow.

- Approve Request
- Reject Request
- Postpone Request

POST /postpone
