# 1 — تركيب النظام من الصفر

> لو عندك `LabDB.accdb` شغالة بالفعل، **ما تتبعش الدليل ده** — هيمسح بياناتك. روح لمجلد `upgrades/`.

---

## المتطلبات
جهاز ويندوز عليه Microsoft Access (2016 أو أحدث يُفضّل).

---

## الخطوات

### 1) أنشئ الملف
- افتح Access ← **Blank database**
- احفظه باسم `LabDB.accdb` في مكان واضح
- هيفتح جدول اسمه Table1 ← **اقفله من غير حفظ**

### 2) الصق الموديولات الأربعة
اضغط **Alt+F11** لفتح محرر الأكواد. لكل ملف من دول، اعمل **Insert ← Module** ثم **Ctrl+A** ثم **Delete** ثم الصق المحتوى:

| الترتيب | الملف | اسم الموديول |
|---|---|---|
| 1 | `src/01_BuildDatabase.bas` | أي اسم |
| 2 | `src/basLab.bas` | **لازم** `basLab` |
| 3 | `src/02_BuildForms.bas` | أي اسم |
| 4 | `src/03_BuildReports.bas` | أي اسم |

> لتسمية الموديول: نافذة **Properties** على الشمال (لو مش ظاهرة اضغط **F4**) ← خانة **(Name)**.

### 3) شغّل الثلاثة بالترتيب
اضغط **Ctrl+G** (نافذة Immediate)، واكتب كل أمر واضغط Enter، واستنى رسالة النجاح قبل اللي بعده:

```
BuildDatabase
```
```
BuildAllForms
```
```
BuildAllReports
```

كل أمر بيطلع رسالة فيها قائمة. **لازم كل السطور تكون `[OK]`.**

### 4) التفعيل
اقفل الملف وافتحه تاني. لو ظهر شريط أصفر فوق اضغط **Enable Content** (ضروري عشان الأزرار تشتغل). المفروض تفتح الشاشة الرئيسية لوحدها.

للتفعيل الدائم: **File ← Options ← Trust Center ← Trust Center Settings ← Trusted Locations** وضيف المجلد اللي فيه الملف.

---

## أخطاء شائعة وحلولها

| الخطأ | السبب | الحل |
|---|---|---|
| `Duplicate Option statement` | Access حط `Option Compare Database` تلقائيًا وإنت لصقت كود فيه نفس السطر | امسح السطر المكرر — لازم يكون مرة واحدة بس في أول الموديول |
| `User-defined type not defined` | مكتبة DAO مش مفعّلة | **Tools ← References** وأشّر على `Microsoft Office XX.0 Access database engine Object Library` |
| `Variable not defined` | سطور `Private Const` مش في أول الموديول | انقلهم تحت `Option Explicit` مباشرة |
| الجداول مش ظاهرة بعد النجاح | لوحة التنقل محتاجة تحديث | اقفل الملف وافتحه، أو اضغط على شريط **All Access Objects** واختار **All Access Objects** |
| رسائل بعلامات `؟؟؟` | لغة ويندوز للبرامج غير Unicode مش عربي | مش مؤثر — الواجهة إنجليزي والبيانات بتتخزن سليمة |

## التأكد إن كل حاجة اتبنت

في نافذة Immediate اكتب:
```
?CurrentDb.TableDefs.Count
```
الرقم المتوقع **16 أو 17** (5 جداول + جداول نظام مخفية). لو طلع 11 أو 12 يبقى الجداول مااتعملتش.

في لوحة التنقل المفروض تلاقي:
- **5 جداول:** Patients, Tests, Orders, Order_Details, tblSettings
- **9 فورمات:** frmMain, frmPatient, frmTests, frmOrder, frmResults, frmSearch + 3 فرعية
- **3 استعلامات** و **3 تقارير**

## بعد التركيب

1. عدّل بيانات معملك: الشاشة الرئيسية ← **Settings (Lab Info)** ← غيّر الاسم والعنوان والتليفون واسم مسؤول التوقيع.
2. احذف التحاليل التجريبية الثلاثة من جدول `Tests`.
3. استورد تحاليلك — شوف `docs/دليل_استيراد_التحاليل_من_Excel.md`.
4. ضيف اللوجو — شوف `docs/03_النشر_والنسخ_الاحتياطي.md`.
