# 3 — اللوجو والنشر والنسخ الاحتياطي

---

## إضافة لوجو المعمل

1. كليك يمين على تقرير **rptResult** ← **Design View**
2. فوق على الشمال فيه مربع فاضي (مكان الصورة) ← اضغط عليه
3. اضغط **F4** لفتح Properties ← تبويب **Format** ← خانة **Picture** ← اختار صورة اللوجو
4. **Ctrl+S** للحفظ ثم اقفل

كرّر نفس الخطوات لـ **rptInvoice** لو عايز لوجو في الإيصال.

---

## النسخ الاحتياطي

قاعدة البيانات كلها **ملف واحد**: `LabDB.accdb`.

**الطريقة الأبسط:** اقفل البرنامج، وانسخ الملف على فلاشة أو مجلد باسم تاريخ اليوم.

**من داخل Access:** `File ← Save As ← Back Up Database`

> اعمل نسخة **كل يوم في نهاية العمل**. ملف واحد تالف من غير نسخة = ضياع كل البيانات.

---

## النشر على أجهزة تانية

### الحقيقة عن ملف `.exe`

Access **مبيتحوّلش** لملف `.exe`. ده مش قصور في المشروع — ده طبيعة البرنامج: الملف `.accdb` هو البرنامج نفسه، ومحتاج Access أو محرّكه عشان يشتغل.

> البرامج اللي بتدّعي تحويل Access لـ exe بتلف الملف في غلاف وبس، وغير موثوقة. متعملش كده.

### البديل الحقيقي: `.accde` + Access Runtime

**1) ملف `.accde` — النسخة المقفولة**

`File ← Save As ← Make ACCDE`

اللي بيحصل:
- الكود بيتحول لصيغة مش قابلة للقراءة أو التعديل
- محدش يقدر يفتح الفورمات أو الأكواد ويعبث فيها
- أسرع في التشغيل

> ⚠️ **مهم جدًا:** ملف `.accde` **مش بيرجع** لـ `.accdb` تاني. احتفظ بالنسخة الأصلية `.accdb` عندك دايمًا — هي دي اللي بتعدّل فيها، والـ`.accde` بتوزّعها.
>
> وما تعملهوش غير بعد ما تخلص: التجربة الكاملة + استيراد التحاليل + الأسعار + بيانات المعمل + اللوجو.

**2) Access Runtime — للأجهزة اللي مفيهاش أكسس**

برنامج **مجاني من مايكروسوفت**. نزّله على الجهاز التاني فيشغّل ملفك زي أي برنامج عادي، من غير ما تشتري رخصة Access ليه.

**النتيجة:** `.accde` + Runtime = من ناحية المستخدم بيشتغل زي برنامج `.exe` بالظبط. اعمل أيقونة على سطح المكتب تفتح الملف، والموظف مش هيحس إنه Access أصلًا.

### التوزيع المقترح

```
جهازك (الأدمن)       →  LabDB.accdb   النسخة الأصلية، بتعدّل فيها
جهاز الاستقبال       →  LabDB.accde   مقفولة، مفيش عبث
```

## العمل على جهازين في نفس الوقت

لو هتشتغل من جهازين على نفس البيانات، **ما تحطش الملف على فلاشة أو تنسخه مرتين** — هتتلخبط النسخ.

الطريقة الصح: **فصل قاعدة البيانات (Split)**
- ملف للجداول (البيانات) على مجلد مشترك على الشبكة
- ملف للفورمات والتقارير على كل جهاز

Access فيه أداة جاهزة لده: **Database Tools ← Access Database ← Move Data / Split Database**

اطلبها لما توصل للمرحلة دي وهتتشرح بالتفصيل.
