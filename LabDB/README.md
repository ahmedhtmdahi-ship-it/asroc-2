# نظام إدارة معمل تحاليل طبية — Access

قاعدة بيانات Microsoft Access لإدارة معمل تحاليل صغير: تسجيل المرضى، طلبات التحاليل، إدخال النتائج، الفواتير، وتقارير PDF بشكل مطابق لاستمارة المعمل.

**واجهة البرنامج إنجليزي** (الأزرار والعناوين)، وبيانات المرضى تتكتب عربي عادي.

## تركيب جديد من الصفر (15 دقيقة)

> لو عندك قاعدة بيانات شغالة بالفعل، **ما تعملش ده** — روح لـ `upgrades/` بدلًا منه.

1. افتح Access ← **Blank database** ← احفظه باسم `LabDB.accdb`.
2. **Alt+F11** ← لكل ملف في `src/` بالترتيب: **Insert ← Module** ثم الصق محتواه.
   - مهم: سمِّ موديول `basLab.bas` باسم `basLab` بالظبط (من نافذة Properties، خانة Name).
3. شغّل الثلاثة بالترتيب من نافذة **Immediate** (`Ctrl+G`):
   ```
   BuildDatabase
   BuildAllForms
   BuildAllReports
   ```
   كل واحد بيطلع رسالة فيها قائمة `[OK]`.
4. اقفل الملف وافتحه ← **Enable Content** ← تفتح الشاشة الرئيسية.

التفاصيل الكاملة وحلول الأخطاء الشائعة في `docs/01_التركيب.md`.

## اللي النظام بيعمله تلقائيًا

| الوظيفة | التفاصيل |
|---|---|
| حساب السن | من تاريخ الميلاد فور إدخاله |
| نسخ سعر التحليل | السعر وقت الطلب يتخزن منفصل، فتغيير الأسعار مش بيأثر على الطلبات القديمة |
| الإجمالي والمتبقي | يتحسبوا لحظيًا في شاشة الطلب |
| علامة H / L | تتحدد تلقائيًا من المدى الطبيعي للتحليل |
| عنوان التقرير | يتغير حسب تصنيف التحليل (Chemistry / Hematology / Microbiology) |
| تصدير PDF | على سطح المكتب باسم يتضمن اسم المريض ورقم الطلب والتاريخ |

## الجداول

| الجدول | الوظيفة |
|---|---|
| `Patients` | بيانات المرضى |
| `Tests` | كتالوج التحاليل: السعر، الوحدة، المدى الطبيعي، التصنيف، طريقة الفحص |
| `Orders` | رأس الطلب: المريض، التاريخ، الحالة، المدفوع، Patient No.، Lab Code، Comments |
| `Order_Details` | سطر لكل تحليل داخل الطلب + نتيجته |
| `tblSettings` | بيانات المعمل (صف واحد): الاسم، العنوان، التليفون، مسؤول التوقيع |

**العلاقات:** كلها بتكامل مرجعي مفروض. حذف الطلب بيحذف تفاصيله (Cascade)، وحذف التحليل من الكتالوج ممنوع لو مستخدم في طلبات.

**حالات الطلب:** `Registered` ← `In Progress` ← `Ready` ← `Delivered`

## حدود النظام الحالي

النظام بيغطي التحاليل العادية (كيمياء، هرمونات، مصل). **مش** مغطي لحد دلوقتي:

- **تقارير الميكروبيولوجي** بجدول الحساسية (بكتيريا + مضادات حيوية + Sensitive/Resistant) — محتاج جداول وشاشات جديدة.
- **صورة الدم الكاملة (CBC)** بشكل الـDifferential Count (نسب + قيم مطلقة محسوبة).

الاتنين دول شغل منفصل ممكن يتضاف بعدين.

## النسخ الاحتياطي

قاعدة البيانات كلها ملف واحد `LabDB.accdb`. اقفل البرنامج وانسخ الملف — دي النسخة الاحتياطية. اعملها يوميًا.

تفاصيل النشر على أجهزة تانية (`.accde` و Access Runtime) في `docs/03_النشر_والنسخ_الاحتياطي.md`.
