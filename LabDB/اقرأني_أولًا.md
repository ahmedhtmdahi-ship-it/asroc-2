# نظام إدارة معمل التحاليل الطبية — دليل شامل

مرحبًا. هذا المجلد يحتوي كل ما تحتاجه لبناء وتشغيل قاعدة بيانات Access لإدارة معملك.
النظام مبني ليعمل على جهاز أو جهازين داخل المعمل، وكل واجهاته عربية من اليمين لليسار.

> **مهم:** لا يمكن تسليم ملف `.accdb` جاهز لأنه صيغة تُبنى داخل برنامج Access على ويندوز فقط. لذلك أعطيتك بدلًا منه **أكوادًا تنسخها وتلصقها وتضغط زرًا** فتبني كل شيء تلقائيًا خلال دقائق. أنت لست بحاجة لأي خبرة برمجية.

---

## ما الذي تحتاجه؟
- جهاز ويندوز عليه **Microsoft Access** (2016 أو أحدث يُفضّل).

## خطوات التركيب من الصفر (مرة واحدة — حوالي 15 دقيقة)

### الخطوة أ — أنشئ الملف
افتح Access ← Blank database ← احفظه باسم `LabDB.accdb` ← أغلق الجدول Table1 دون حفظ.

### الخطوة ب — المرحلة 1 (الجداول)
Alt+F11 ← Insert ← Module ← الصق `01_BuildDatabase.bas` ← ضع المؤشر في `BuildDatabase` ← F5.

### الخطوة ج — المرحلة 2 (الفورمات)
- Insert ← Module ← الصق `basLab.bas` ← سمِّ الوحدة `basLab` (من F4، خانة Name).
- Insert ← Module ← الصق `02_BuildForms.bas` ← ضع المؤشر في `BuildAllForms` ← F5.

### الخطوة د — المرحلة 3 (التقارير)
Insert ← Module ← الصق `03_BuildReports.bas` ← ضع المؤشر في `BuildAllReports` ← F5.

### الخطوة هـ — التفعيل
أغلق الملف وافتحه ← اضغط **Enable Content** لو ظهر شريط أصفر ← تفتح الشاشة الرئيسية.

> تفاصيل كل خطوة (وحلول أي أخطاء) موجودة في ملف الدليل الخاص بكل مرحلة.

## الاستخدام اليومي (باختصار)

| أريد أن... | الطريق |
|---|---|
| أسجّل مريضًا | الشاشة الرئيسية ← مريض جديد ← املأ الاسم (مطلوب) ← حفظ |
| أعمل طلب تحاليل | طلب تحاليل جديد ← اختر المريض ← اختر التحاليل (السعر يُنسخ تلقائيًا) ← اكتب المدفوع ← حفظ + طباعة إيصال PDF |
| أدخل نتائج | إدخال النتائج ← اختر الطلب ← اكتب النتيجة (الحالة تُحدَّد تلقائيًا) ← حفظ + الطلب جاهز ← تصدير تقرير النتيجة PDF |
| أبحث عن مريض وسجله | بحث عن مريض ← اختر المريض ← تظهر كل طلباته |
| أضيف/أعدّل تحليلًا وسعره | إدارة التحاليل والأسعار |
| أعدّل بيانات المعمل في التقارير | الإعدادات (بيانات المعمل) |

ملفات PDF تُحفظ دائمًا على **سطح المكتب** باسم يتضمن اسم المريض ورقم الطلب والتاريخ.

## النسخ الاحتياطي (افعله يوميًا)

قاعدة البيانات كلها ملف واحد: `LabDB.accdb`.
- أبسط طريقة: أغلق البرنامج، وانسخ الملف إلى فلاشة أو مجلد باسم تاريخ اليوم.
- بديل من داخل Access: **File ← Save As ← Back Up Database**.
- لو تعمل على جهازين: ضع الملف في مجلد مشترك على الشبكة، وافتحه من الجهازين. للأمان على المدى الطويل يُفضّل فصل الجداول في ملف والفورمات في ملف آخر (Split Database) — أخبرني إن وصلت لهذه المرحلة وأشرحها لك.

---

## لو واجهت أي خطأ

كل باني (Build) مصمّم بحيث يخبرك باسم العنصر الذي فشل ووصف الخطأ. **انسخ سطر [فشل] وأرسله لي** وسأصلحه لك بدقة. لا تقلق — البيانات لا تُمسّ عند إعادة بناء الفورمات أو التقارير.
